# AutoClicker for Minecraft PvP

Универсальный автокликер для Minecraft PvP, оптимизированный для работы в играх.

## Возможности

- 🖱️ **Раздельные настройки ЛКМ/ПКМ**: Независимая скорость кликов для левой и правой кнопки мыши
- 🎲 **Рандомизация (Legit Mode)**: Настраиваемый разброс интервалов для обхода античитов
- 🔑 **Горячая клавиша**: Переназначаемая клавиша включения/выключения
- 🔔 **Звуковые уведомления**: Beep сигналы при переключении (можно отключить)
- 🖥️ **Оверлей**: Всегда поверх окон индикатор статуса (работает в оконном режиме)
- ⚙️ **Сохранение настроек**: Все параметры сохраняются между сессиями

## Установка

### Готовый EXE
1. Скачайте последний релиз из [Releases](../../releases)
2. Запустите `AutoClicker.exe` (потребуются права администратора)

### Из исходников
```bash
pip install -r requirements.txt
python autoclicker.py
```

## Использование

1. Запустите программу (от имени администратора)
2. Настройте скорость кликов (CPS) для ЛКМ и ПКМ
3. При желании включите рандомизацию (Legit Mode)
4. Нажмите горячую клавишу (по умолчанию `F6`) для активации
5. Зажмите кнопку мыши — автокликер будет кликать с заданной скоростью

## Настройки

- **Скорость (CPS)**: 1-100 кликов в секунду
- **Сила разброса**: 0-100% рандомизации интервала между кликами
- **Горячая клавиша**: Любая клавиша для вкл/выкл
- **Звук**: Включение/выключение beep уведомлений
- **Оверлей**: Показать/скрыть индикатор статуса

## Требования

- Windows 10/11
- Python 3.10+ (для запуска из исходников)
- PyQt5

## Сборка EXE

```bash
pip install pyinstaller
pyinstaller AutoClicker.spec
```

Готовый файл будет в папке `dist/`.
